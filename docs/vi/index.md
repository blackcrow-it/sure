# Tài liệu Sure bằng tiếng Việt

Bộ tài liệu phản chiếu đường dẫn repository tại `docs/vi/<đường-dẫn-gốc>`. Toàn bộ 71 tài liệu trong mục lục đã được đọc đối chiếu và hiệu đính. Khi cần đối chiếu thuật ngữ hoặc theo dõi thay đổi mới, dùng liên kết tới bản tiếng Anh.

## Thuật ngữ thống nhất

| English | Tiếng Việt |
| --- | --- |
| account | tài khoản |
| family / household | hộ gia đình |
| transaction | giao dịch |
| budget | ngân sách |
| net worth | giá trị tài sản ròng |
| holding | khoản nắm giữ |
| liability | khoản nợ |
| provider | nhà cung cấp |
| merchant | đơn vị bán hàng |

Giữ nguyên tên sản phẩm, định danh, khóa cấu hình, lệnh và ví dụ mã. Dùng tiếng Việt không đồng nghĩa đổi tiền tệ sang VND. Các tài liệu `llm-guides` là bản tham khảo; chính sách gốc vẫn nằm trong tài liệu tiếng Anh và file chỉ dẫn của repository.

## Phạm vi và kiểm tra

Inventory ban đầu gồm **71 tài liệu, 106.094 từ**. Không dịch LICENSE, `AGENTS.md`, `CLAUDE.md`, hai adapter `.github/copilot-instructions.md`, `.junie/guidelines.md`, hoặc `docs/superpowers/**`. File cấu hình và OpenAPI sinh tự động được liên kết về nguồn, không nhân bản.

Bản gốc chỉ thêm liên kết chuyển ngôn ngữ, ngoại trừ đoạn thông báo desktop được cập nhật theo thay đổi đã được coordinator yêu cầu. Không thực thi lệnh triển khai, migration hoặc thiết lập cơ sở dữ liệu trong tài liệu.

Chạy kiểm tra cấu trúc bằng `python docs/vi/_tools/validate.py` tại root repository. Công cụ kiểm tra coverage, code block, inline code, liên kết file và anchor cục bộ; không truy cập mạng và không chứng minh độ chính xác ngữ nghĩa của bản dịch.

Xem [báo cáo kiểm chứng và phần còn lại](translation-report.md).
